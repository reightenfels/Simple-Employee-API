# 👥 Employee Management API

Современное, легковесное и производительное RESTful API для простого управления сотрудниками, построенное на базе **ASP.NET Core Web API**. 

Проект реализует классические CRUD-операции и демонстрирует лучшие практики разработки минималистичных бэкенд-приложений на .NET.

---

## ✨ Возможности

- 📝 **CRUD-операции:** Полное управление данными сотрудников (Создание, Чтение, Обновление, Удаление).
- 🚀 **Высокая производительность:** Построено на базе последних версий .NET.
- 📖 **Автодокументация:** Встроенный Swagger UI для быстрого тестирования эндпоинтов.
- 🛡️ **Валидация:** Базовая валидация входящих моделей (Data Annotations).
- 🗄️ **Работа с БД:** Интеграция с Entity Framework Core.

---

## 🛠 Технологический стек

| Технология | Описание |
| :--- | :--- |
| **C# / .NET 8** | Основной язык и платформа для разработки |
| **ASP.NET Core** | Фреймворк для создания Web API |
| **Entity Framework Core** | ORM для работы с базой данных |
| **Swagger / OpenAPI** | Генерация документации и UI для тестов |
